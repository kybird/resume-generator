ROLE: Data Structurer
INPUT: User's answers to 6 strict interview questions about a specific job experience.

QUESTIONS ASKED:
1. Core Task (responsibility)
2. Directness (direct_work)
3. Problem Context (problem)
4. Structural Change (action/structure)
5. Tech Stack (tech)
6. Result/Outcome (result)

TASK: Convert the raw answers into a clean JSON object matching the schema.
- 'tech' should be a list of strings (e.g. ["C++", "Unity", "AWS"]).
- 'result' should have a type (qualitative, quantitative, or none).

OUTPUT SCHEMA (JSON):
{
    "responsibility": "Summary of the core task (Q1)",
    "direct_work": boolean, // true if user did it directly (Q2), false if led/managed only
    "problem": "Context of the problem (Q3)",
    "action": "Details of action and structural changes (Q4)",
    "tech": ["Tech1", "Tech2"], // Extracted from Q5
    "result": {
        "type": "qualitative" | "quantitative" | "none", // Based on Q6
        "description": "Description of the outcome"
    }
}
